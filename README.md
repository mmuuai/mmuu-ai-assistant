# MMUU AI 助手

AI 工具管理助手

一个窗口管理 Claude、Codex、Grok、Cursor、Kimi、DeepSeek 等十多个 AI 软件：账号与中转站一键切换、内置代理与环境检测、技能安装和会话交接。对话记录始终是同一份。

## 下载

到 [Releases](https://github.com/mmuuai/mmuu-ai-assistant/releases) 下载最新版，按自己的电脑选：

- **Windows 10 / 11（64 位）**：`…-Windows-x64.zip`
- **Mac（Apple 芯片）**：`…-macOS-AppleSilicon.zip`
- **Mac（Intel 芯片）**：`…-macOS-Intel.zip`

安装步骤和 Mac 第一次打开的放行方法写在每个版本的说明里。使用中遇到问题欢迎在 [Issues](https://github.com/mmuuai/mmuu-ai-assistant/issues) 反馈问题。

## 能做什么

- **账号一键切换**：每个软件可以保存多个账号或中转站，点一下就换，不用反复登录；切换前后对话记录始终是同一份。
- **额度一眼看清**：各账号的用量、限流和到期情况集中显示，需要处理的账号在首页提醒。
- **内置代理**：导入订阅、选好节点后，需要代理的国外 AI 软件固定从所选节点联网，国内软件照常直连。
- **环境检测**：检查这台电脑访问国外 AI 服务时对外呈现的环境，能修正的一键修正。
- **技能安装**：把常用的 Agent 技能先放进你的个人知识库统一管理，再同步到各个 AI 软件。
- **会话交接**：把一个软件里的工作进度打包，换账号或换软件后接着做。

## 隐私

账号与登录信息只保存在你的电脑上，本工具不会上传到作者的服务器；使用时只直接连接各软件的官方服务或你自行添加的中转站。

## 支持的系统

Windows 10 / 11（64 位）；macOS 13 及以上（Apple 芯片与 Intel）。
